🦠 COVID-19 Cases Prediction Using Machine Learning
📌 Project Description

This is a simple Machine Learning and Data Analysis mini project for analyzing COVID-19 data and predicting the number of COVID-19 cases based on historical information.

📌 Features
Date
Country / State
Total Cases
New Cases
Total Deaths
New Deaths
Total Recovered
Active Cases
Population
Vaccination Rate
Case Growth Rate
🎯 Target / Analysis

The project analyzes:

Total COVID-19 Cases
New Cases per Day
Total Deaths
Total Recovered Cases
Active Cases
COVID-19 Cases by Country/State
Monthly/Weekly COVID-19 Trends
Death Rate
Recovery Rate
COVID-19 Cases Prediction
🤖 Machine Learning Target

Target Variable: New Cases or Total Cases

The model learns from historical COVID-19 data and predicts future COVID-19 cases.

Python Machine Learning
